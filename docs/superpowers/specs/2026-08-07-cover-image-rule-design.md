# 头图识别规则 - 设计

日期：2026-08-07

## 背景

排版时模型有时会把正文第一张图挪用为封面/头图，因为 skill 只定义了封面组件的图片槽位，却没有规定图片来源。

## 规则（用户确认）

1. 仅当 Markdown 的第一个内容元素就是图片（图片上方没有任何文字/标题/引言等）时，该图识别为头图
2. 头图填入所选主题封面/头图组件的图片槽位，正文中不再重复出现该图
3. 其余一切情况（文档以文字/标题开头，或主题没有头图图片槽位）：封面组件一律用无图版，所有图片作为正文图片按原文位置保留，严禁挪用正文图片作封面/头图

## 涉及文件

| 文件 | 改动 |
|------|------|
| `public/themes/SKILL.md` | 新增"头图识别规则"小节（解析结构步骤附近） |
| `public/themes/theme-moyu-green.md` | cover-breaking 封面组件两个版本注释明确图片来源规则 |
| `src/lib/llm/promptBuilder.ts` | 有图文章注入头图规则（强化，防模型忽略 SKILL） |
| `public/themes/theme-generator.md` | 自定义主题封面组件须遵守头图来源规则 |

## 验证

- `npm run lint` / `npm run build` 通过
- 抽查生成的 system prompt 包含头图规则
